# Model fitting setup gate

MODEL_FITTING_SETUP_GATE

- requested final quantity: observed one-way group F statistic and fixed-seed permutation p-value for petal-length differences among Iris species
- final quantity type: model statistic and p-value, with group summaries as supporting empirical quantities
- response variable and units: petal length in centimeters
- predictor variables and units: species, a three-level categorical label
- predictor transformations or parsing rules: remove the `Iris-` prefix only for output labels; retain exact source group membership
- mixture component labels and ratio-token order: not applicable
- row scope rule from the question: all complete plant records in the corrected official data file
- rows explicitly excluded from fitting: none; wholly empty trailing records are file formatting and not observations
- handling of controls, baselines, endpoints, and missing values: no control or endpoint class; reject nonempty malformed or missing records
- endpoint-scope sensitivity plan, if pure/boundary rows exist: not applicable
- duplicate or replicate handling: every source row is one independent observed plant; do not collapse or deduplicate
- model candidates, formulas, and fixed parameters: one-way fixed group-effects ANOVA statistic only; no model selection; permutation null generated by shuffling species labels across fixed measurements
- model selection metric and convention: not applicable
- optimization/evaluation domain: observed 150 records and their three source labels
- final extraction rule: report the observed F statistic and Monte Carlo permutation p-value `(1 + exceedances) / (1 + permutations)` using 20,000 permutations and random seed 1936

The setup is accepted before computation because the response, predictor,
row scope, statistic, permutation mechanism, random seed, and final quantities
are explicit. The test evaluates association and does not establish causation.
