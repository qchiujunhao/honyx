# Data source

This package uses the corrected `bezdekIris.data` file from the UCI Machine
Learning Repository's Iris dataset.

- Creator: R. A. Fisher
- Repository dataset ID: 53
- DOI: `10.24432/C56C76`
- Dataset page: `https://archive.ics.uci.edu/dataset/53/iris`
- Retrieved file: `https://archive.ics.uci.edu/ml/machine-learning-databases/iris/bezdekIris.data`
- Retrieval date: 2026-07-20
- License reported by the repository: CC BY 4.0
- Packaged filename: `inputs/bezdek-iris.data`
- SHA-256: `0fed2a99db77ec533a62dc66894d3ec6df3b58b6a8f3cf4a6b47e4086b7f97dc`

The file contains 150 nonempty records. Each record contains sepal length,
sepal width, petal length, petal width, and an Iris species label. Measurements
are in centimeters. The final empty record is treated as file formatting rather
than as a scientific observation.
